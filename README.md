# defigraph-ai

AI-powered exploratory analysis for Solidity repositories.

⚠️ This tool is NOT a security audit.
It helps developers, auditors, and founders quickly understand how a protocol works.

## What it does
- Analyzes Solidity repositories
- Builds a mental model of the protocol
- Generates flows, use cases, and assumptions
- Prepares the ground for audits
